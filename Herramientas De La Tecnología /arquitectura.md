# Arquitectura

Este proyecto utiliza una arquitectura basada en frontend desacoplado con uso de servicios externos (SaaS).

## Enfoque

- Aplicación basada en HTML, CSS y JavaScript
- Sin backend propio
- Delegación de lógica compleja a servicios externos

## Flujo

1. Usuario interactúa con la interfaz
2. Acciones clave redirigen a servicios externos
3. El procesamiento ocurre fuera del sistema

## Ventajas

- Simplicidad
- Rápida implementación
- Bajo mantenimiento

## Limitaciones

- Dependencia de terceros
- Escalabilidad limitada sin backend
