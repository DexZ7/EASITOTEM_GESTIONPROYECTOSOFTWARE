# Descripción del proyecto

EASITOTEM es un proyecto de desarrollo web diseñado para la barbería TOTEM, cuyo propósito es digitalizar y optimizar el proceso de gestión de citas.

La plataforma permitirá que los clientes puedan agendar una cita de forma rápida, sencilla e intuitiva, sin necesidad de crear una cuenta, realizando la reserva como invitados y eligiendo al barbero de su preferencia de acuerdo con la disponibilidad existente.

El pago de los servicios continuará realizándose de manera presencial en la barbería, por lo que la plataforma estará enfocada exclusivamente en la administración y organización de las citas.

# Objetivo

Desarrollar una aplicación web que permita administrar eficientemente las citas de la barbería TOTEM, mejorando la organización del negocio y ofreciendo una mejor experiencia tanto para los clientes como para los barberos.

# Problemática

Actualmente, la gestión de citas se realiza mediante mensajes o llamadas, lo que puede provocar:

Doble asignación de horarios.
Errores al registrar citas.
Pérdida de tiempo en la organización de la agenda.
Dificultad para conocer la disponibilidad de cada barbero.
Interrupciones constantes durante la jornada laboral.
Solución propuesta

EASITOTEM centraliza la administración de citas mediante una plataforma web que permitirá:

Agendar citas de forma sencilla.
Consultar horarios disponibles.
Seleccionar al barbero de preferencia.
Evitar conflictos entre horarios.
Organizar automáticamente la agenda de trabajo.
Facilitar la administración del negocio.

# Beneficios

Para los clientes

Reservar una cita en cualquier momento.
Elegir al barbero de su preferencia.
Conocer la disponibilidad de horarios.
Reducir tiempos de espera.
Proceso de reserva rápido e intuitivo.

Para la barbería

Mejor organización de las citas.
Optimización del tiempo de trabajo.
Eliminación de conflictos de horarios.
Mayor productividad de los barberos.
Mejor atención al cliente.
Reducción de errores administrativos.

# Funcionalidades principales

- Registro de citas como invitado.

- Selección del servicio.

- Selección del barbero.

- Consulta de horarios disponibles.

- Administración de la agenda.

- Confirmación de la cita.

- Panel de administración para gestionar citas.

- Gestión de los horarios de cada barbero.
